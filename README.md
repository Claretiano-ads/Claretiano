# Introdução à Programação Web

Este repositório reúne as aulas e atividades da disciplina de Introdução à Programação Web, com foco no desenvolvimento de páginas e aplicações web básicas.

## Mensagem para os alunos

Neste semestre, vamos aprender os fundamentos da programação web de forma prática e progressiva. Começaremos com HTML para estruturar páginas, CSS para estilizar e organizar o visual, JavaScript para adicionar interatividade e PHP para trabalhar com lógica no lado do servidor. O objetivo é que você desenvolva uma base sólida para entender como sites e sistemas web funcionam e consiga criar seus próprios projetos com autonomia.

## O que vamos estudar

- HTML: estrutura e organização de páginas web
- CSS: estilização e layout
- JavaScript: interatividade e comportamento das páginas
- PHP: lógica de programação e desenvolvimento web básico

## Objetivo da disciplina

Desenvolver habilidades básicas para criar páginas web, compreender a lógica por trás do funcionamento da internet e iniciar o aprendizado em programação web com foco em prática e resolução de problemas.

## Como usar este repositório

Cada pasta ou arquivo pode representar uma aula, exercício ou atividade. Acompanhe as instruções das aulas e pratique os conteúdos para consolidar o aprendizado.
